## 專案簡介

VocaBuddy 是一個透過 Google Colab 執行的英文單字學習工具。

使用者可以透過單字卡的方式瀏覽英文單字及其中文意思。本組在原有程式的基礎上新增單字，並加入隨機跳轉單字與顯示目前單字卡編號等功能，使單字卡的操作更加方便。

## 本次新增的單字與功能

### 新增單字

| 單字 | 中文意思 |
| --- | --- |
| `ecstatic` | 狂喜 |
| `resilience` | 韌性；恢復力 |
| `enraged` | 憤怒 |

### 新增功能

- **隨機跳轉單字按鈕**
  - 可以隨機跳轉至其他單字卡，方便使用者以隨機方式複習單字。

- **顯示目前單字卡編號**
  - 顯示目前正在瀏覽的單字卡編號，讓使用者知道目前所在的單字卡。
